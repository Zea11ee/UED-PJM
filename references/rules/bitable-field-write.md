# Bitable 字段写入规则

**规则**：项目管理表的单选/多选字段，写入时必须使用选项"名称"字符串，不可使用 option_id。

**触发条件**：
- 向 `UED 项目管理` 多维表格写入记录
- 涉及 SingleSelect 或 MultiSelect 类型字段
- 包括但不限于：优先级、状态、业务线等字段

**正确写法**：
```json
{
  "优先级": "P2",
  "状态": "未启动"
}
```

**错误写法**：
```json
{
  "优先级": "optXXXXXX",
  "状态": "optYYYYYY"
}
```

**来源**：2026-02-04 项目管理表 SingleSelect 写入产生乱码选项事件。

**反例**：
- 若写入 option_id，Bitable 会把未知 id 当作新文本选项创建
- 导致选项列表出现乱码选项
- 需要手动清理无效选项

**修复方法**：
- 发现乱码选项后，立即改用名称字符串重新写入
- 在多维表格管理界面删除无效选项
